Ten pictures, then three clips

The page already works with the ten pictures alone: it fades from one view to the next as you scroll. The three clips are what turn that into a moving camera, so make the pictures first and the clips second. Each card turns green by itself when its file is in place.

This description fills into the prompts below. Change it only if you want a different watch.

Three rules that matter: every picture must show the same watch; the watch should sit in the middle of the frame (words appear at the sides and bottom); and there should be no brand name or lettering on the dial. If a picture changes the watch's design, regenerate it. Generate four at a time and keep the most dramatic one: this watch is meant to look like a sculpture, not like something from a shop window.

1 The watch from the front

Text to image. This is the master picture and the top of the page. Every other picture uses it as a reference, so retry until you like the watch.

2 Three more camera positions

Image to image, with the master as reference each time. These are the places the camera stops as you scroll.

3 The other three dial colours

Image to image, with 04-stand-magma as reference. Only the dial colour changes, so the watch stays still when a visitor picks a colour.

4 Three close-ups of it being made

Image to image, with the master as reference so the parts match the watch. These fill the three cards lower down the page.

5 Three clips that join the camera positions

Image to video. Each clip starts on one picture and should end on the next. If you can set an end frame, use the picture named on the card. If there is no place for an end frame, use the start frame alone; the clips can still be joined afterwards.

When all three clips are in assets/clips, say so. They then get sharpened on this computer and turned into the frame sequence the page plays. Until that is done the page keeps using the still pictures.

5b Or: one 15-second clip

Three separate clips each slow down at their start and end, so the camera hesitates twice on the way round. One long clip moves at a steady speed with no joins. Make this in place of clips A, B and C, not as well as them.

Before you generate, look at the Generate button. If 15 seconds is still free on Unlimited at 480p, go ahead. If it shows a credit cost, stop and say so: the three-clip version can be smoothed on this computer for free.
